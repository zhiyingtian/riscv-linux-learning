## 3. 关键设计

```text
VMA 是“映射意图”，PTE 是“映射结果”；惰性映射让二者先不同步。
mm_mmap 只建 VMA；mm_access 第一次访问才缺页分配匿名页 + 写 PTE。
```

- VM flags 与 `MM_PROT_*` 同值，`vm_flags` 可直接传给 `mm_map/mm_protect`；
- `find_vma` 语义：第一个 `vm_end > addr`，不保证包含 addr；
- 匿名页归 mm 所有，`mm_destroy` 要同时回收匿名页和页表页。
